# Platform brand assets

The source cards use official platform artwork strictly to identify where each saved source originated.

- `InstagramBrandIcon`: full-color gradient glyph from Meta's [Instagram brand asset pack](https://www.meta.com/brand/resources/instagram/instagram-brand/).
- `YouTubeBrandIcon`: full-color red digital icon from YouTube's [brand resources](https://brand.youtube/youtube-icon).

The PNGs were downloaded from the official packs on September 6, 2026 and resized proportionally for the iOS asset catalog. Their colors, artwork, and clear space were not otherwise modified. Each icon appears inside the source card that links directly to the corresponding platform content.

## Welcome screen

- `JotWordmarkLogo`: the full orange bookmark and white pin from the existing app icon, prepared with a transparent outer background for the approved welcome-screen design. The original app icon remains the source artwork. The transparent version was prepared with the built-in image-generation tool on September 16, 2026, using the request to preserve the complete bookmark and white pin and remove only the external white background.
- `GoogleSignInMark`: Google's current multicolor G, downloaded unchanged from https://developers.google.com/static/identity/images/g-logo.png on September 16, 2026. Used only to identify the Google authentication action.
- `GoogleSans-Medium.ttf`: the unmodified Medium static font from the official [Google Sans v14.000 release](https://github.com/googlefonts/googlesans/releases/tag/v14.000). Its SIL Open Font License is bundled alongside the font in `PlaceLogger/Fonts/GoogleSans-OFL.txt`.

The welcome button uses “Continue with Google,” with Google's neutral light palette and outlined dark palette. Reference: [Sign in with Google branding guidelines](https://developers.google.com/identity/branding-guidelines). The Apple button uses the native system control.
